# Submission checklist

- [ ] Source code reviewed and working tree reviewed
- [ ] README and installation guide included
- [ ] Migrations, factories and Seeder included
- [ ] ERD included
- [ ] Report document prepared from `docs/report-outline.md`
- [ ] Real screenshots captured using `docs/evidence/screenshot-checklist.md`
- [ ] Manual test cases completed
- [ ] Automated tests pass on MySQL `hr_management_testing`
- [ ] GitHub Actions pass verified after the final push
- [ ] Team member names and contributions verified
- [ ] Demo accounts verified from `DatabaseSeeder`
- [ ] `.env` excluded from Git
- [ ] No real secrets or production credentials included
- [ ] Runtime uploads excluded from Git
- [ ] Production deployment guide reviewed
- [ ] Final demo flow rehearsed using `docs/demo-checklist.md`

Do not mark screenshot, teamwork or CI items complete until a human verifies them.
