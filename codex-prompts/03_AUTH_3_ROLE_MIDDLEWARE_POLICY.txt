php artisan breeze:install blade

Nếu đã có auth tương đương: giữ nguyên, không cài lại.

B. ROLE
Tạo migration bổ sung users.role:
admin | hr | employee
default employee.
Nếu chưa có users.account_status thì thêm:
active | locked
default active.

C. USER MODEL HELPERS

isHr(): bool
isEmployee(): bool
hasRole(string|array $roles): bool

D. ROLE MIDDLEWARE
app/Http/Middleware/RoleMiddleware.php
- auth required.
- nhận variadic role.
- sai role => abort(403).
Đăng ký alias trong bootstrap/app.php theo Laravel 12.

Route groups:
- /admin/*: auth + role:admin
- /hr/*: auth + role:admin,hr
- /employee/*: auth + role:employee
